# Game cover art

One image per game, used as the cover on event cards, Home, and the Events featured row.

- File name = game id, `.jpg`: `pokemon.jpg`, `one_piece.jpg`, `mtg.jpg`, ... (ids below)
- Size: 1600 x 1000 px (16:10), JPG, under 300 KB
- Keep the subject in the upper two thirds. Titles sit over the bottom third on a dark gradient.
- No text or logos baked into the image. The app adds the event name.
- `general.jpg` is the fallback for network events and games without art.

Until an image exists the app shows a gradient in the game's color.

Ids: general, one_piece, pokemon, mtg, gundam, star_wars_unlimited, vanguard, lorcana, uvs, digimon,
yugioh, riftbound, hololive, weiss, sw_legion, union_arena, warhammer, azuki, blood_bowl, bolt_action
